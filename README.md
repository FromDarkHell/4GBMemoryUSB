# 4GBMemoryUSB

This is a USB dongle for connecting an Xbox 360 4GB Internal Memory Module to your PC.
These modules are basically a complete USB implementation, but with a 3.3V VCC rather than 5V (which is standard for USB). So, this board is just a USB plug, alongside a voltage regulator to go from 5V to 3.3V.
